# README 配图延续已认可的风格（2026-11-17）

- **触发场景 / 适用范围**：后续调整本项目 README 的工程流程图、对比图和排障图时；用户提出新方向时重新确认适用性，不推广为所有项目的审美规则。
- **用户反馈**：原有图片被指出观感不佳；参考社区提示词生成的工作流预览获得认可，用户随后要求三张配图统一采用该方向。
- **可执行规则**：
  1. 以已认可的工作流总览为视觉参考，延续米白背景、深炭线条、低饱和青绿和少量陶土橙；采用简洁二维图形及清楚的层级。
  2. 每张图只解释一个主要关系，控制标签数量和长度；不能靠缩小字体塞入全部规则。
  3. 保存实际提交的生成提示词，区分公开参考、改编内容及实际输出。
  4. 核对图中标签与技能规则；排障图的“运行时取证路径”不冒充全部执行分支。
- **检查方式**：核对标签和箭头，在约 900px 内容宽度及 390px 视口检查显示；关键技能名和命令仍在正文保留可复制文本。
